# キャラクター口調表叩き台 — Vol.1

> 作成: 2026-11-20。対象: Vol.1 (ch001–021)。
> これは**叩き台**であり、裁定ではない。一人称・二人称・語尾の候補は、ユーザーの決定後に [決定] へ更新する。
> 根拠: `04_style_guide.md` Character Voice Rules、各キャラカードの Voice 節、Vol.1 本文。
> 原作の恒常ルール: Bog の Nia への感情は内面モノローグで明言されない (彼は思っていても、文章に書かれない)。翻訳でも説明を足さない。

## Bog
- 原文の声: 粗く、気楽で、好色で、行き当たりばったり。その下に静かな狡さ。他人の恐怖や真剣さに対する、気づかない deadpan (04_style_guide / bog.md Voice)。
- 日本語: 一人称は「俺」[決定 2026-11-20]。二人称は相手により「お前」「おたく」[決定 2026-11-20: 「あんた」は使わない]。語尾は短く平らに (だな、だろ、ぞ、か)。褒め言葉は素直で大きい。地球文化の知識は自信満々にズレている — 訳でも「知ったかぶりのズレ」を説明せず、そのまま置く。
- 罵り: **Holy Val** を使う (地球人の damn とは分ける。用語リスト参照)。
- Nia への呼び名: **squeeze candy** (実在の米国の菓子名の転用。彼女のゼリー状の便をからかう下ネタで、優しさは一切ない)。**pickle は絶対に Bog の口から出ない** — あれは Nia 側の侮辱語 (原作裁定)。
- 禁止: "That's a lot of paperwork" 的な決め台詞の deadpan は Claude の癖であり Bog の特性ではない (2026-11-19 裁定)。日本語でも「書類が増えるな」的な常套句を Bog の口癖として作らない。paperwork の語自体は通常の意味 (書類・行政) では使ってよい。
- 言い淀み: "gen-gentle-man" のような言い直しは日本語でも再現する [決定 2026-11-20: 「し、しん、紳士」]。

## Nia Okonkwo (Black Huntress)
- 原文の声: 鈍く率直 (blunt)、激しく庇護的、実務的、脅しに屈しない。乾いたユーモア。いじめっ子への忍耐なし (nia_okonkwo.md Voice)。ヒーローとしてはドライでクール、家庭生活の暖かさがそのギャップ (ユーザーの整理原則)。
- **訛りについての作者意図 (2026-11-20)**: 原文で彼女が標準語なのは作者の英語能力の限界によるもので、本来は**ボルチモアのナイジェリアンコミュニティらしい訛り**を出したかった、とのこと。彼女は移民2世で英語は母語 — つまり「外国人の片言」ではなく「地元コミュニティのアクセント」。カード側にも作者意図として記録済み。
- **カノン (2026-11-20): 感情が高ぶると AAVE が出る。**
- **日本語訳の裁定 (2026-11-20): Nia の AAVE に相当する日本語は横須賀弁とする。** 平時は制御された標準寄りの声、感情が上がる場面ほど横須賀弁が濃く出る、という勾配で再現する。横須賀弁の特徴仕様 (語尾・一人称・特徴語彙の固定セット) は別途小さく作って本節に足す。
  - 選択の理由 (ユーザー 2026-11-20): 港町・労働者階級の荒さ・米軍基地の街という点に加え、**大都市圏との近さ**。ボルチモアは DC やニューヨークに近い大都市圏の中の都市であり、その訛りは「田舎の言葉」ではなく都市の言葉。横須賀も東京・横浜の大都市圏に属する都市の方言であり、この位置関係が対応する。
- 日本語: 一人称は「あたし」[決定 2026-11-20]。Bog には呼び捨て・「あんた」。文は短く切り、怒りは声量でなく乾きで出す。内面モノローグは辛辣で具体的 (数える、査定する、言い訳を自分で却下する)。
- **横須賀弁の特徴仕様 (試案 2026-11-20、ch001試訳時に作成・要ユーザー確認)**: ch001 には Nia の台詞がないため未検証。次章以降で勾配を検証しながら調整する。戯画化を避け、語尾中心の小さな固定セットに留める。
  - 平時 (薄い): 語尾は標準寄り。「じゃん」を確認・同意で時折使う程度に留め、「だべ」は使わない。一人称「あたし」は不変。
  - 上昇時 (中): 文末に「じゃん」「じゃんか」を増やす。否定・断定を短く切る (例: 「違うじゃん」「知らない」)。「～だべ」が断定で単発に出始める。
  - 高ぶり時 (濃い): 「だべ」「～べ」「じゃんか」が連続しうる。命令・制止は短い形 (例: 「触るな」「やめろ」) のまま、方言は語尾で濃くする。語彙は原則として増やさない。
  - 使わないもの (試案): 「おっぺす」(押す)、「でんぼ」(尻) 等の三浦半島の古い特徴語彙は、Nia の都市的な声には載せない (漁港の古層の語彙であり、ボルチモア都市部に対応しないため)。「うっせぇ」等の汎用的な粗い若者語で方言の代用をしない。
  - 内面モノローグ: 地の文寄りの内面では平時の薄さを保ち、感情のピークの文だけ濃くする。連祷 (tomato, Scotch bonnet, thyme; Amara, Chidi, Daniel.) には方言を一切載せない (唱え言葉として固定)。
- 署名パターン: 数えること (count)。連祷は **"tomato, Scotch bonnet, thyme; Amara, Chidi, Daniel."** — 訳は全編固定 (用語リスト §5)。料理の型そのものが唱え言葉。
- ♥: 興奮・動揺時に、本人の意志に反して語の間に ♥ が出る。Bog への本物の愛情が燃料になっている分、彼女のは制御しにくい (04_style_guide)。表記ルールは文体ルール側 (直前語に密着、空白なし)。
- 侮辱語: Bog を **pickle** / **overgrown cactus** と呼ぶ。帰属を逆にしない。
- 注意: 彼女の言葉が「当たる」、鈴が「応える」等の表現は比喩であり、首輪装着中に物理的な呪い・力を働かせるのではない (Figurative Language Policy)。翻訳で実在の超常効果にしない。

## Sonya (Sofiya Ivanova / Pale Murderess) — Vol.1 では ch019–021 のみ
- 原文の声: 短く、冷たく、落ち着いている。柔らかく均一なトーン。ロシア語の罵りとキリル文字の思考 (04_style_guide / sonya_ivanova.md Voice)。
- 日本語: 一人称は「私」[決定 2026-11-20]。文は極端に短く、感情を温度でなく欠落で出す。敬語は使わないが、乱暴にもしない — 冷たい平坦さ。
- ロシア語: キリル文字を原文ママ本文に置き、日本語訳をルビで振る [決定 2026-11-20]。彼女の "Не сдамся" は署名句。
- ♥: 罵りながらでも、興奮時には ♥ が出る (04_style_guide)。

## Daniel Okonkwo — Vol.1 では主に言及・回想
- Nia の夫。元 ER 医師。穏やかで、からかい合う夫婦の型がある (Coming to America の台詞の応酬、辛い物が苦手で "pepper is a condiment, not an ingredient")。
- 日本語の叩き台: 引用・回想で声が出る場合は、穏やかな医師の口調。Nia との関係は **夫** であり、consort ではない (用語リスト §1 の罠を参照)。

## 脇の声 (Vol.1)
- **商人 (Val merchant)**: 売り口上。飛び蜥蜴の格言 (配偶者と子のいる優れた雌を捕れ…) は動物の話として語られるが、Val の一部が女性についても抱く考えの写しでもある (canon)。口上の調子で訳し、地の文で解説を足さない。
- **registrar**: 事務的・手続き的。誓いの場面の硬さを出す。
- **Platoon Leader**: 軍の命令口調。最後通牒 (ch002) の圧を短文で。
- **地の文 (narrator)**: 三人称・過去形。ダークコメディとスラップスティック。背景の固有名詞は具体名のまま訳す (スタイル裁定 2026-11-20)。月名・暦日付は書かない (原作ルール)。季節の手がかりは季節帯に大まかに沿うが、気候異常の世界なので不相応な天候はそのまま (canon)。
