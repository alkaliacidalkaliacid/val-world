# Prompt 04: Hierarchical Rollup (use only when an arc ends)

## When to use it
- Only when an arc ends. Not after every chapter.

## Steps
1. From all chapter summaries in that arc, create the arc summary (150-200 words) → arcs/arcXX.md
2. Based on the arc summary, rewrite 01_synopsis.md (appending is forbidden, keep it within 200-250 words)
3. From then on, do not include that arc's chapter summaries in context

## Prompt
```
From the chapter summaries below, create an arc summary. Do not refer to the prose.

Requirements:
- 150-200 words max
- Keep: turning points, established facts, character changes, what carries over
- Drop: subplots, dialogue details, repeated descriptions
- After that, using the existing full synopsis and the new arc summary, rewrite the full synopsis from scratch within 200-250 words. Appending is forbidden.

[Paste chapter summaries and the existing full synopsis here]
```
