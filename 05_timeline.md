# 05_timeline.md - Story Timeline (one row per chapter)

> Purpose: the single source for in-story time. Added 2026-11-18 after ch096
> invented an unsupported "three days ago" — the instance tracked who/where/what
> but not *when*, so durations were being improvised.

## Rules
- **Anchor**: Day 1 = the day Bog bought Nia (ch001). Count days from the anchor.
  No calendar dates in prose (the year itself is provisional: 2047).
- One row per chapter: start point, elapsed time inside the chapter, end point.
- A duration stated in prose ("three days ago", "a week later") must be
  derivable from this file. If it is not derivable, it does not get written.
- Mark reconstructed spans that rest on inference as [est.]; never silently
  canonise an estimate.
- Context packs include only the current position plus the last ~10 rows.

## Parallel threads (added 2026-11-19, from arc04 onward)
- There is **one global clock**. Threads are not given separate tables; the
  Thread column says whose action the chapter follows, and each row records
  that thread's window on the shared Day count.
- The Basis column must state the relation to the **previous chapter of the
  same thread**: `continuous` / `+N days` / `overlaps ch##` (its window
  overlaps another chapter's) / `catch-up` (the thread resumes behind the
  latest time shown and moves forward).
- **Sync points**: a chapter where threads meet in one scene is marked
  [sync] — the windows of all threads present must coincide there. A
  mismatch at a sync point is a timeline error.
- Where a thread has a monotonic internal clock (e.g. the monster's
  vocabulary count, module numbers), record its value in Basis; it verifies
  chapter order inside the thread even when days cannot be fixed.
- The Current position lists a per-thread "as of" whenever threads have
  diverged, not just the global latest time.

## Season bands (added 2026-11-20, user ruling)
Nominal seasons per span, derived from the two anchors the prose actually
fixes: ch013's outdoor planting of tomato and Scotch bonnet seedlings
("planted last week" — spring planting) and the current position's full
warm season (ch119–122: naked sunbathing in northern Alabama, biting
insects, lush kudzu). Everything between is [est.], absorbed by the
ch013→ch014 gap of 1–2 months and the other unstated gaps. No month names
in prose, per the standing rule.
- arc01 (ch001–013): late winter / early spring → **spring** [est.]
- ch013→ch014 gap: spring → **late spring**
- arc02–07 (ch014–090): **early summer → summer** [est.]
- arc08 (ch091–present): **summer** (anchored by ch119–122)
- Caveat: per 00_canon.md (Climate), the war has made Earth's climate
  abnormal, so scene-level weather may deviate from these bands freely.
  The bands fix the broad time of year, not any given day's weather.
