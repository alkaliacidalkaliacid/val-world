# CONTEXT_PACK.md - The Fixed List of What to Include Every Time

> Purpose: Keep the tokens you pass constant, no matter which chapter you're on. This is the heart of this template.

## What to include when generating prose (nothing else)
| File | Every time | Approx. tokens |
|---|---|---|
| 01_synopsis.md | Yes | ~300 |
| Current arc summary | Yes | ~250 |
| 02_current_state.yaml | Yes | ~400 |
| 03_open_threads.md (open only) | Yes | ~300 |
| 05_timeline.md (current position + last ~10 rows only) | Yes | ~150 |
| 04_style_guide.md | Yes | ~500 |
| Character cards for appearing characters (2-4) | Yes | ~800 |
| lore/relationships.md — Pack Layer only, or the pair sections for appearing pairs (2-4 pairs max) | Yes | ~450 |
| Last 1-2 chapter summaries | Yes | ~200 |
| This chapter's beat sheet | Yes | ~300 |
| Previous scene prose (only when continuity requires it) | Optional | ~800 |
| **Total target** |  | **~3,950-4,750** |

## What NOT to include
- Full prose of past chapters
- Chapter summaries from finished arcs
- Character cards for characters not appearing
- Resolved foreshadowing
- The full text of 00_canon.md (include only excerpts for chapters where the worldbuilding matters)
- The full text of lore/relationships.md (reference layer: full Current State and the append-only History Log). Include only its Pack Layer, or the Current sections of the pairs actually appearing — the History Log is archive and is pulled only for the one pair a chapter deliberately revisits, if any

## Check (ask yourself before generating)
- [ ] Is the total around 5,000 tokens or less?
- [ ] Does the beat sheet include something different from the previous chapter?
- [ ] Are open threads at 15 or fewer?
