# Relationships — THE ASHEN DOMINION

> Created 2026-11-21 at the user's direction: character relationships are
> tracked here as a dedicated record, with change history preserved.
>
> **How to maintain this file**
> - **Current State** (below) is overwritten at each chapter close — it always
>   shows the state as of the latest closed chapter.
> - **History Log** is **append-only**. Never rewrite or delete a past entry.
>   When a relationship changes, add a new dated entry under that pair, even
>   if it reverses an earlier entry. The reversal is the history.
> - Record only what the manuscript / user rulings establish. Mark reader-only
>   knowledge (interior chapters, narrator asides) as `[reader-known]` and
>   keep it distinct from what the other character knows in-world.
> - Loyalty percentages are the General Control System values from
>   `lore/val_devices.md`; `[est.]` values are the author's reconstructed
>   progression, not in-prose displays (except ch115).
> - Terminology: Val-side bonds are **consort**; `wife` / `husband` are
>   reserved for Earth-human marriages (see `00_canon.md`, Glossary).
>
> **Context-window rule (added 2026-11-21 — read this before including
> this file in any context pack)**
> This file as a whole is **reference layer only** and is never included
> in full: at ch130 it is ~5,300 words (~7,000+ tokens), which alone
> would exceed the entire CONTEXT_PACK budget (~4,000–5,000 tokens).
> It uses the same two-layer structure as the character cards:
> - **Pack layer = the "Pack Layer" section directly below** (333 words).
>   This, or the one-line `relationships:` dicts in
>   `02_current_state.yaml`, is all that goes into a chapter pack.
> - **Per-chapter selection:** when a chapter turns on a specific pair,
>   pull *only that pair's* Current section (2–4 pairs at most), never
>   the whole Current State.
> - **History Log = archive.** It is append-only by design and will keep
>   growing; it is pulled only when a chapter deliberately revisits a
>   past change, and then only that pair's entries. Its growth therefore
>   costs zero tokens in ordinary chapters.
