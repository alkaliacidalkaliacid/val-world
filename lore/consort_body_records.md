> Loyalty is a separate log (`lore/val_devices.md`): body changes track

## Rules of the record
- **Units:** the yard–pound system throughout, per the general rule
  (user ruling, 2026-11-21; `04_style_guide.md`, Style — "Units":
  the yard–pound system governs the main text and all configuration
  files). Heights in feet and inches, weights in pounds, B/W/H in
  inches, rounded to the nearest whole unit. The figures were
  first drafted in metric and converted the same day; the imperial
  values are now the record, and deltas are computed from them.
- **Baseline:** the measurement set at the start of the recorded period
  for each woman (named per woman below). **Current:** the set as of
  the latest chapter on file (ch130 at establishment).
- **A change entry** needs: chapter anchor, cause (ingestion / regimen /
  other), and the delta or the qualitative change. Non-mensural changes
  (function, senses, fluids) are logged as their own entry type — Rin's
  ch105 entry is the first.
- Most characters are simply not in this record. It covers the four
  consorts only: Nia, Sonya, Priya, Rin.
